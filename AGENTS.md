# Project Guidelines

This project is a standalone React 19 + TypeScript + Vite frontend template for an Internship Management & Digital Logbook application.

## Key Principles
- **Pure Frontend Template**: The project uses an in-memory client-side mock store (`src/lib/mock-data.ts`) with no backend or database dependencies required to run.
- **Styling**: Tailwind CSS v4 and Radix UI primitives.
- **Routing**: TanStack Router.
